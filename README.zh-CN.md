# r-data-lineage-plotting

用于构建可追溯、可复现 R 数据分析与绘图流程的 AI Skill。

## 项目背景

科研 R 项目经常出现：

- 原始数据与计算数据混放；
- 图形依赖隐藏步骤；
- 数据来源无法追踪；
- 修改上游数据后结果无法同步。

本项目用于建立明确的数据血缘管理体系。

## 核心理念

每一个图都应该具有完整来源：

```text
原始数据
 ↓
数据处理
 ↓
分析对象
 ↓
绘图
 ↓
最终图件
```

## 设计原则

- 原始数据保持不可修改；
- 分析结果具有明确来源；
- 每个图形脚本包含输入、处理、分析和输出；
- 保证科研结果可复现。

## 适用场景

- 生态学分析；
- 微生物组研究；
- 多组学研究；
- 高质量论文图件制作。

## 目标

建立科研级、可审计、可长期维护的 R 分析流程。
